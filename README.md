Here are the **official and most useful links** you should bookmark and use when you get stuck:

### FastAPI (Official)
- **Main Documentation**: [https://fastapi.tiangolo.com/](https://fastapi.tiangolo.com/)
- **Tutorial (start here)**: [https://fastapi.tiangolo.com/tutorial/](https://fastapi.tiangolo.com/tutorial/)
- **Dependencies** (very important for understanding `Depends`): [https://fastapi.tiangolo.com/tutorial/dependencies/](https://fastapi.tiangolo.com/tutorial/dependencies/)
- **SQL Databases** (official way using SQLModel): [https://fastapi.tiangolo.com/tutorial/sql-databases/](https://fastapi.tiangolo.com/tutorial/sql-databases/)
- **Advanced User Guide**: [https://fastapi.tiangolo.com/advanced/](https://fastapi.tiangolo.com/advanced/)
- **Source Code**: [https://github.com/fastapi/fastapi](https://github.com/fastapi/fastapi)

### SQLAlchemy (Official)
- **Main Site**: [https://www.sqlalchemy.org/](https://www.sqlalchemy.org/)
- **Documentation (2.0 style – recommended)**: [https://docs.sqlalchemy.org/en/20/](https://docs.sqlalchemy.org/en/20/)
- **Unified Tutorial** (best place to learn properly): [https://docs.sqlalchemy.org/en/20/tutorial/](https://docs.sqlalchemy.org/en/20/tutorial/)
- **Source Code**: [https://github.com/sqlalchemy/sqlalchemy](https://github.com/sqlalchemy/sqlalchemy)

### Bonus (Highly Recommended)
- **SQLModel** (made by the same person who made FastAPI – combines SQLAlchemy + Pydantic):  
  [https://sqlmodel.tiangolo.com/](https://sqlmodel.tiangolo.com/)

---

**How to use these properly (20–25 min rule):**

1. When you are stuck on something (example: session management, `Depends`, relationship, etc.), open the relevant page.
2. Read only the section related to your problem — don’t try to read everything.
3. After reading, close the docs and try to explain it in your own words or write a small test.
